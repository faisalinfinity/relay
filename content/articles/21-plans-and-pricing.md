# Plans and pricing

|                                           | **Solo**    | **Studio**  | **Pro**     |
| ----------------------------------------- | ----------- | ----------- | ----------- |
| Price (monthly billing)                   | $19 / month | $49 / month | $99 / month |
| Staff members                             | 1           | up to 10    | unlimited   |
| SMS credits per month                     | 100         | 500         | 2,000       |
| Platform fee on payments                  | 1%          | 0.5%        | none        |
| Calendar sync, reminders, online payments | ✓           | ✓           | ✓           |
| Custom domain for booking page            |             |             | ✓           |
| API access and webhooks                   |             |             | ✓           |
| Custom email sender name                  |             |             | ✓           |
| Priority support                          |             |             | ✓           |

Prices are in US dollars and exclude sales tax or VAT, which is added at checkout based on your billing
address.

## Annual billing

Pay yearly and get **two months free**: $190 for Solo, $490 for Studio, $990 for Pro.

## Free trial

New accounts get **14 days of the Studio plan free**, with no card needed. If you don't choose a plan by the
end of the trial, your booking page is paused until you do. Nothing is deleted.

## Which plan is right for me?

- Working on your own: **Solo**.
- A studio with a team, using Slotwise's own booking page or widget: **Studio**.
- You need your own domain, you want to connect other software through the API, or you take enough
  payments that the platform fee matters: **Pro**.

To switch plans, see [Changing or cancelling your plan](22-changing-or-cancelling-your-plan.md).
